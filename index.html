Privacidad y registro de visitas

Si aceptas, enviaremos al canal de Discord configurado tu dirección IP, navegador (User-Agent), la página visitada y la fecha y hora. También consultaremos una API externa para obtener una ubicación aproximada (país, región, ciudad, código postal y coordenadas si están disponibles) y una señal del tipo de conexión, que no confirma si usas VPN. Esa API recibirá tu IP. No recopilamos tu correo ni tu identidad de Discord. Si rechazas, podrás usar el sitio normalmente y no enviaremos ese registro. Puedes cambiar tu elección cuando quieras desde el pie de página.

Vercel, el proveedor de geolocalización y Discord procesarán los datos descritos para generar y entregar el registro. Consulta la política de privacidad.
